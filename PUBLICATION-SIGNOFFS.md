# Publication sign-offs

Engineering verification does not substitute for accountable human approval. The following decisions must be completed by an authorized Decionis representative before the next public announcement.

| Decision                    | Evidence reviewed                                                            | Accountable owner                             | Status                           |
| --------------------------- | ---------------------------------------------------------------------------- | --------------------------------------------- | -------------------------------- |
| Fixture provenance          | `fixtures/manifest.json`, `FIXTURE-PROVENANCE.md`, policies, examples, tests | `security@decionis.com` (data/security owner) | Owner assigned; approval pending |
| Trademark and naming        | `TRADEMARKS.md`, package name, repository name, README                       | Decionis Inc. (brand owner)                   | Owner assigned; approval pending |
| Disclosure response targets | `SECURITY.md` response and disclosure table                                  | `security@decionis.com` (security owner)      | Owner assigned; approval pending |

The supplied ownership identities are recorded here, but ownership is not a substitute for approval. An authorized human should replace each pending status with their name, role, approval date, and any conditions in a dedicated pull request. Until then, the approvals remain explicit publication gaps.
