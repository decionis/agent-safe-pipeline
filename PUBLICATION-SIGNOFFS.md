# Publication sign-offs

Engineering verification does not substitute for accountable human approval. The following decisions must be completed by an authorized Decionis representative before the next public announcement.

| Decision                    | Evidence reviewed                                                      | Required approver             | Status                   |
| --------------------------- | ---------------------------------------------------------------------- | ----------------------------- | ------------------------ |
| Fixture provenance          | `FIXTURE-PROVENANCE.md`, conformance vector, policies, examples, tests | Data or security owner        | Pending written approval |
| Trademark and naming        | `TRADEMARKS.md`, package name, repository name, README                 | Decionis brand or legal owner | Pending written approval |
| Disclosure response targets | `SECURITY.md` response and disclosure table                            | Security response owner       | Pending written approval |

Approvers should replace the status with their name, role, approval date, and any conditions in a dedicated pull request. Until then, these are explicit publication gaps.
